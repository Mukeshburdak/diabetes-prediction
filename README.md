# diabetes-prediction
This project focuses on building a machine learning model to predict the likelihood of diabetes in individuals based on health-related data. Using the Pima Indians Diabetes Dataset, the model leverages features such as glucose level, BMI, age, and insulin concentration to identify patterns associated with diabetes onset. The workflow includes data preprocessing, exploratory data analysis (EDA), model training using algorithms like Logistic Regression, Random Forest, and XGBoost, and evaluation using accuracy, precision, recall, and ROC-AUC metrics. The final model aims to assist healthcare professionals or end users in early risk detection, promoting timely intervention and disease prevention. Optionally, a simple web interface is provided for real-time prediction input.
